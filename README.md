# Semantic Search Notes

A semantic search prototype over personal notes/documents, using sentence embeddings and cosine similarity to retrieve relevant text by meaning rather than exact keyword matches.

## What's in here
- Embedding generation using `sentence-transformers`
- Cosine similarity implemented from scratch (NumPy) alongside library comparisons
- A basic semantic search CLI over a personal document set
